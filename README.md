# Silencify

**English** | [Türkçe](README.tr.md)

A small Windows app that automatically mutes Spotify when an ad starts playing and unmutes it when the ad end. (!IT DOES NOT BLOCK ADS!)

<img width="1775" height="412" alt="image" src="https://github.com/user-attachments/assets/77552826-c4f8-4925-aa47-bbc5df7a4ec7" />

## Download

**[Download Silencify.exe](../../releases/latest/download/Silencify.exe)** (Windows 10/11)

Just double-click the file, no installation needed. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

## How does it work?

1. While Spotify is playing music, it detects when an ad starts.
2. When an ad is detected, it mutes Spotify.
3. When the ad ends, it unmutes Spotify.
